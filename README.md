# TeamFlow

Internal project-management tool (Jira-inspired) for a small team: projects, issues, Kanban board,
sprints, comments, notifications and reports.

- Backend: FastAPI, SQLAlchemy 2, SQLite, Alembic (`backend/`)
- Frontend: React + Vite + TypeScript (`frontend/`, from Phase 5)
